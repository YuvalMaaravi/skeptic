# SKEPTIC

הבית מאורגן לפי השאלה של המשתמש: אבחון, טיפול, השוואה, פתרון אסתטי, שיחה ולמידה. ההשוואה מתפצלת למוצרים, טיפולים, קליניקות ופתרונות אסתטיים. כל פריט נשמר פעם אחת בקטלוג, גם כשהוא שייך לכמה מסלולים, עם רמת ראיות ומקור.

זה סיכום מידע, לא ייעוץ רפואי.

## הרצה

```bash
npm install
npm run dev
```

הקטלוג עצמו יושב ב-`src/data/catalog.ts`. תוויות בעברית ב-`src/data/labels.ts`.

## מה נכנס למעבר הזה

תרופות מרשם, תכשירים, PRP ו-iPRF, השתלות, מיקרונידלינג, לייזר, תוספים, תרופות סבתא, הסוואה, ואיך ניגשים לרופא, לבית מרקחת ולהשתלה בארץ או בחו״ל.

## מה עדיין לא

כיסוי קופות וביקורות משתמשים. מחירי מוצרים ומרפאות שנכנסו הם ציטוט מעמוד שפורסם, עם תאריך הבדיקה, לא דירוג תוצאה.
